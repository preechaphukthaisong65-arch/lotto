# Lotto

Android application project.

## Current scope

- Main screen UI only.
- Main menu: ขายหวย, รายงานยอด, ประวัติ, บัญชีเชื่อ, ตั้งค่า.
- UI components are separated by responsibility.
- No database, API, network integration, or business logic has been added.

## Android project

- Kotlin
- Jetpack Compose
- Material 3
